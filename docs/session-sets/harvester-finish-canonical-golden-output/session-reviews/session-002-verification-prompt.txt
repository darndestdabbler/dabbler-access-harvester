# Appendix A — Aggregator API (Session 1 lock, not changed this session):

## Appendix A — Aggregator API (Session 1 lock)

`AccessHarvester.Pipeline.Manifest.DatabaseManifestAggregator` is
a static class with one public entry point. Every input is
optional (default `null`); the aggregator skips missing inputs
and produces a minimal valid manifest from whatever is supplied.
This matches the existing `UnresolvedItemAggregator.Build(...)`
contract.

```csharp
public static DatabaseManifest Build(
    DatabaseInfo database,
    string harvesterVersion,
    IEnumerable<FormExport>?               forms                       = null,
    IEnumerable<FormExport>?               reports                     = null,
    IEnumerable<QueryAbstraction>?         queries                     = null,
    IEnumerable<ModuleExport>?             modules                     = null,
    IEnumerable<TableMetadata>?            tables                      = null,
    IEnumerable<RelationshipMetadata>?     relationships               = null,
    IEnumerable<ValidationRule>?           validationRules             = null,
    IEnumerable<RowSourceSpec>?            rowSourceSpecs              = null,
    IEnumerable<FunctionClassification>?   functionClassifications     = null,
    IEnumerable<EventHandlerClassification>? eventHandlerClassifications = null,
    NavigationGraph?                       navigationGraph             = null,
    IEnumerable<UnresolvedItem>?           unresolvedItems             = null,
    IEnumerable<HarvesterDiagnostic>?      diagnostics                 = null);
```

Contract:

- **Required inputs:** `database` and `harvesterVersion`. The
  schema's `DatabaseManifest.required` is
  `["SchemaType", "SchemaVersion", "HarvesterVersion", "Database"]`;
  `SchemaType` and `SchemaVersion` are constants the aggregator
  emits ("DatabaseManifest" and "1.0" respectively). The other
  two come from the caller.
- **All collection inputs:** treated as null-or-empty equivalent.
  An empty collection produces an empty array in the manifest
  (the schema permits zero-length arrays); a null collection
  produces an empty array too — the manifest never has a
  collection slot set to JSON `null`.
- **Determinism:** the aggregator does **not** re-sort the inputs.
  Callers pass already-deterministic ordering; the aggregator
  preserves it verbatim. (`UnresolvedItemAggregator` does its own
  multi-key sort because it merges from multiple sources;
  `DatabaseManifestAggregator` merges nothing — each input is a
  single source — so the responsibility is the caller's.)
- **Summary:** `DatabaseSummary` is computed from the populated
  collections — `FormCount = forms?.Count() ?? 0`, etc. — so the
  manifest is internally consistent.
- **No I/O:** the aggregator does not read or write files. Callers
  serialize the returned `DatabaseManifest` themselves.

## 2. AccessHarvester.Core/Pipeline.cs (FULL file)

```csharp
using System.Globalization;
using System.Reflection;
using System.Text.Json;
using System.Text.Json.Serialization;
using AccessHarvester.Core.Abstractions;
using AccessHarvester.Core.Com;
using AccessHarvester.Core.Enrichment;
using AccessHarvester.Core.Extraction;
using AccessHarvester.Core.Translation;
using AccessHarvester.Pipeline.Enrichment;
using AccessHarvester.Pipeline.Manifest;

namespace AccessHarvester.Core;

/// <summary>
/// Orchestrates the three-phase pipeline: extract Access objects to raw/ artifacts,
/// translate those into kb/ JSON, then enrich into ir/ JSON (normalized geometry,
/// etc.). Phases are independently callable.
/// </summary>
public sealed class Pipeline
{
    private readonly IReadOnlyList<IObjectExporter> _exporters;
    private readonly IReadOnlyList<IObjectTranslator> _translators;
    private readonly IReadOnlyList<IObjectEnricher> _enrichers;

    public Pipeline(
        IEnumerable<IObjectExporter> exporters,
        IEnumerable<IObjectTranslator> translators,
        IEnumerable<IObjectEnricher> enrichers)
    {
        _exporters = exporters.ToArray();
        _translators = translators.ToArray();
        _enrichers = enrichers.ToArray();
    }

    /// <summary>
    /// Returns a new Pipeline with only the exporters/translators whose Category
    /// appears in <paramref name="categories"/> (case-insensitive match).
    /// </summary>
    public Pipeline WithCategories(IEnumerable<string> categories)
    {
        var set = new HashSet<string>(categories, StringComparer.OrdinalIgnoreCase);
        return new Pipeline(
            _exporters.Where(e => set.Contains(e.Category)),
            _translators.Where(t => set.Contains(t.Category)),
            _enrichers.Where(e => set.Contains(e.Category)));
    }

    public IReadOnlyList<string> ExporterCategories
        => _exporters.Select(e => e.Category).ToArray();

    public IReadOnlyList<string> TranslatorCategories
        => _translators.Select(t => t.Category).ToArray();

    /// <summary>
    /// Default pipeline covering all categories the harvester currently supports.
    /// </summary>
    public static Pipeline Default() => new(
        exporters: new IObjectExporter[]
        {
            SaveAsTextExporter.Forms,
            SaveAsTextExporter.Reports,
            SaveAsTextExporter.Macros,
            SaveAsTextExporter.Modules,
            QueryExporter.Instance,
            TableExporter.Instance,
            RelationshipExporter.Instance,
        },
        translators: new IObjectTranslator[]
        {
            SaveAsTextTranslator.Forms,
            SaveAsTextTranslator.Reports,
            SaveAsTextTranslator.Macros,
            SaveAsTextTranslator.Modules,
            JsonPassthroughTranslator.Queries,
            JsonPassthroughTranslator.Tables,
            JsonPassthroughTranslator.Relationships,
        },
        enrichers: new IObjectEnricher[]
        {
            GeometryEnricher.Forms,
            GeometryEnricher.Reports,
            LabelResolver.Forms,
            LabelResolver.Reports,
            PropertyDecoder.Forms,
            PropertyDecoder.Reports,
            TextCapacityEnricher.Forms,
            TextCapacityEnricher.Reports,
            VbaSignatureEnricher.Forms,
            VbaSignatureEnricher.Reports,
            VbaSignatureEnricher.ModulesAndClasses,
            MacroActionsEnricher.Macros,
            MacroActionsEnricher.Forms,
            MacroActionsEnricher.Reports,
        });

    public static string BaseDir(string outputRoot, string dbName)
        => Path.Combine(outputRoot, "AccessMetaData", dbName);

    public static string RawDir(string outputRoot, string dbName)
        => Path.Combine(BaseDir(outputRoot, dbName), "raw");

    public static string KbDir(string outputRoot, string dbName)
        => Path.Combine(BaseDir(outputRoot, dbName), "kb");

    public static string IrDir(string outputRoot, string dbName)
        => Path.Combine(BaseDir(outputRoot, dbName), "ir");

    public ExtractResult Extract(string databasePath, string outputRoot)
    {
        string dbName = Path.GetFileNameWithoutExtension(databasePath);
        string baseDir = BaseDir(outputRoot, dbName);
        string rawDir = RawDir(outputRoot, dbName);
        Directory.CreateDirectory(rawDir);

        var categories = new List<CategoryExportResult>();
        using var session = new AccessComSession(databasePath);
        foreach (var exporter in _exporters)
        {
            var categoryDir = Path.Combine(rawDir, exporter.Category);
            var outcomes = exporter.Export(session, categoryDir);
            categories.Add(new CategoryExportResult(exporter.Category, outcomes));
        }

        return new ExtractResult(baseDir, rawDir, categories);
    }

    public TranslateResult Translate(string rawDir, string kbDir)
    {
        Directory.CreateDirectory(kbDir);
        var categories = new List<CategoryTranslateResult>();
        foreach (var translator in _translators)
        {
            var rawCategoryDir = Path.Combine(rawDir, translator.Category);
            var kbCategoryDir = Path.Combine(kbDir, translator.Category);
            var outcomes = translator.Translate(rawCategoryDir, kbCategoryDir);
            categories.Add(new CategoryTranslateResult(translator.Category, outcomes));
        }
        return new TranslateResult(rawDir, kbDir, categories);
    }

    public EnrichResult Enrich(string kbDir, string irDir)
    {
        Directory.CreateDirectory(irDir);
        var categories = new List<CategoryEnrichResult>();

        WriteDefaultsArtifact(irDir);

        if (!Directory.Exists(kbDir))
            return new EnrichResult(kbDir, irDir, categories);

        foreach (var kbCategoryDir in Directory.GetDirectories(kbDir))
        {
            string categoryName = Path.GetFileName(kbCategoryDir);
            string irCategoryDir = Path.Combine(irDir, categoryName);
            Directory.CreateDirectory(irCategoryDir);

            var categoryEnrichers = _enrichers
                .Where(e => e.Category.Equals(categoryName, StringComparison.OrdinalIgnoreCase))
                .ToList();

            var outcomes = new List<EnrichOutcome>();
            foreach (var file in Directory.GetFiles(kbCategoryDir, "*.json"))
            {
                string name = Path.GetFileNameWithoutExtension(file);
                string targetFile = Path.Combine(irCategoryDir, name + ".ir.json");
                try
                {
                    if (categoryEnrichers.Count == 0)
                    {
                        File.Copy(file, targetFile, overwrite: true);
                    }
                    else
                    {
                        // First enricher reads from kb/ and writes to ir/.
                        // Subsequent enrichers read and rewrite the ir/ file in place,
                        // each adding its own contribution. Enrichers run in the order
                        // registered in the Pipeline's constructor.
                        categoryEnrichers[0].EnrichFile(file, targetFile);
                        for (int i = 1; i < categoryEnrichers.Count; i++)
                            categoryEnrichers[i].EnrichFile(targetFile, targetFile);
                    }
                    outcomes.Add(new EnrichOutcome(name, true));
                }
                catch (Exception ex)
                {
                    outcomes.Add(new EnrichOutcome(name, false, ex.Message));
                }
            }
            categories.Add(new CategoryEnrichResult(categoryName, outcomes));
        }

        return new EnrichResult(kbDir, irDir, categories);
    }

    private static void WriteDefaultsArtifact(string irDir)
    {
        var asm = typeof(Pipeline).Assembly;
        const string resourceName = "AccessHarvester.Core.Resources.property-defaults.json";
        using var stream = asm.GetManifestResourceStream(resourceName);
        if (stream is null) return;
        using var reader = new StreamReader(stream);
        File.WriteAllText(Path.Combine(irDir, "Defaults.json"), reader.ReadToEnd());
    }

    public RunResult Run(string databasePath, string outputRoot)
    {
        var extract = Extract(databasePath, outputRoot);
        string dbName = Path.GetFileNameWithoutExtension(databasePath);
        string kbDir = KbDir(outputRoot, dbName);
        var translate = Translate(extract.RawDir, kbDir);
        string irDir = IrDir(outputRoot, dbName);
        var enrich = Enrich(translate.KbDir, irDir);

        EmitManifestArtifacts(extract.BaseDir, databasePath);

        return new RunResult(
            extract.BaseDir, extract.RawDir, translate.KbDir, enrich.IrDir,
            extract.Categories, translate.Categories, enrich.Categories);
    }

    // V1 manifest emission: assemble a DatabaseManifest from whatever
    // strongly-typed inputs Pipeline.Run() can supply today and write
    // both manifest.json and unresolved-items.json to <baseDir>. The
    // per-category collection inputs (Forms/Reports/Queries/Modules/
    // Tables/Relationships/etc.) are owned by their respective builders
    // (FormComponentSpecBuilder, QueryAbstractionBuilder, ...) and are
    // not threaded through Pipeline.Run() yet — the aggregator's contract
    // accepts a minimal set and emits a schema-valid envelope, so this
    // wiring lands the emission seam. Collection population grows in
    // follow-on sessions.
    //
    // The UnresolvedItems list is built once and serialised to both
    // files: it lives inline inside manifest.json AND as a bare array in
    // unresolved-items.json so downstream tooling that wants the
    // manual-review queue does not have to deserialise the whole manifest
    // (per the Session 2 spec).
    private static void EmitManifestArtifacts(string baseDir, string databasePath)
    {
        var database = new DatabaseInfo
        {
            Name = Path.GetFileName(databasePath),
            FilePath = Path.GetFullPath(databasePath),
            ExportedAt = DateTimeOffset.UtcNow.ToString("o", CultureInfo.InvariantCulture),
        };

        IReadOnlyList<UnresolvedItem> unresolvedItems = Array.Empty<UnresolvedItem>();

        var manifest = DatabaseManifestAggregator.Build(
            database: database,
            harvesterVersion: ResolveHarvesterVersion(),
            unresolvedItems: unresolvedItems);

        var options = new JsonSerializerOptions
        {
            WriteIndented = true,
            DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull,
        };

        File.WriteAllText(
            Path.Combine(baseDir, "manifest.json"),
            JsonSerializer.Serialize(manifest, options));
        File.WriteAllText(
            Path.Combine(baseDir, "unresolved-items.json"),
            JsonSerializer.Serialize(unresolvedItems, options));
    }

    private static string ResolveHarvesterVersion()
    {
        var asm = typeof(Pipeline).Assembly;
        var info = asm.GetCustomAttribute<AssemblyInformationalVersionAttribute>();
        if (!string.IsNullOrEmpty(info?.InformationalVersion))
            return info!.InformationalVersion;
        return asm.GetName().Version?.ToString() ?? "0.0.0";
    }
}

public sealed record CategoryExportResult(string Category, IReadOnlyList<ExportOutcome> Outcomes);
public sealed record CategoryTranslateResult(string Category, IReadOnlyList<TranslateOutcome> Outcomes);
public sealed record CategoryEnrichResult(string Category, IReadOnlyList<EnrichOutcome> Outcomes);

public sealed record ExtractResult(string BaseDir, string RawDir, IReadOnlyList<CategoryExportResult> Categories);
public sealed record TranslateResult(string RawDir, string KbDir, IReadOnlyList<CategoryTranslateResult> Categories);
public sealed record EnrichResult(string KbDir, string IrDir, IReadOnlyList<CategoryEnrichResult> Categories);
public sealed record RunResult(
    string BaseDir,
    string RawDir,
    string KbDir,
    string IrDir,
    IReadOnlyList<CategoryExportResult> Extract,
    IReadOnlyList<CategoryTranslateResult> Translate,
    IReadOnlyList<CategoryEnrichResult> Enrich);

```

Notes on the new wiring:
- Pipeline.Run() now calls EmitManifestArtifacts(extract.BaseDir, databasePath) after Enrich() and before returning RunResult.
- EmitManifestArtifacts builds a DatabaseInfo (Name + absolute FilePath + ISO-8601 ExportedAt), constructs an empty UnresolvedItem array, calls DatabaseManifestAggregator.Build, serializes manifest to <baseDir>/manifest.json and the array to <baseDir>/unresolved-items.json with WriteIndented=true and DefaultIgnoreCondition=WhenWritingNull.
- ResolveHarvesterVersion reads AssemblyInformationalVersionAttribute, falls back to AssemblyName.Version, falls back to "0.0.0".

```csharp
// Full Extract -> Translate -> Enrich pipeline against a committed
// sample .accdb. SkippableFact-gated for hosts without Microsoft Access.

[SupportedOSPlatform("windows")]

    public void Pipeline_RunAgainstMiniComplex_EmitsRawKbIrTreesForFormsCategory()

        string db = Path.Combine(RepoPaths.Samples(), "MiniComplex.accdb");

            var result = pipeline.Run(db, outRoot);

            Assert.All(result.Extract,
                c => Assert.All(c.Outcomes, o => Assert.True(o.Success, o.ErrorMessage)));
            Assert.All(result.Translate,
                c => Assert.All(c.Outcomes, o => Assert.True(o.Success, o.ErrorMessage)));
            Assert.All(result.Enrich,
                c => Assert.All(c.Outcomes, o => Assert.True(o.Success, o.ErrorMessage)));

            // Tier directories exist under the conventional layout.
            Assert.True(Directory.Exists(result.RawDir), $"raw dir missing: {result.RawDir}");
            Assert.True(Directory.Exists(result.KbDir),  $"kb dir missing: {result.KbDir}");
            Assert.True(Directory.Exists(result.IrDir),  $"ir dir missing: {result.IrDir}");

            // Forms tier emitted at least one ir file. The exact form list
            // depends on MiniComplex.accdb's contents and is asserted only
            // as "non-empty" — the regression-snapshot suite (Session 2)
            // is where exact expected outputs get pinned.
            //
            // Both checks are mandatory, not conditional: if the pipeline
            // regresses to the point of dropping the Forms category
            // directory entirely, this test must fail rather than silently
            // pass on a missing-directory branch.

                $"category directory is absent — contract regression.");
            var irFiles = Directory.GetFiles(formsIrDir, "*.ir.json", SearchOption.TopDirectoryOnly);
            Assert.True(
                irFiles.Any(),
                $"Expected at least one Forms/*.ir.json under {formsIrDir}. " +
                $"Pipeline reported no extract failures, so empty output indicates a contract change.");

            // Session 2 emission gates: manifest.json and unresolved-items.json
            // land alongside raw/, kb/, ir/ at <baseDir>. The contract is
            // verified at the file-existence + minimal-shape level here; full
            // schema validation lives in ManifestSchemaConformanceTests.
            string manifestPath = Path.Combine(result.BaseDir, "manifest.json");
            string unresolvedPath = Path.Combine(result.BaseDir, "unresolved-items.json");

            Assert.True(File.Exists(manifestPath),
                $"Expected manifest at {manifestPath}. Pipeline.Run() must emit the rolled-up " +
                $"DatabaseManifest after Enrich() — contract regression.");
            Assert.True(File.Exists(unresolvedPath),
                $"Expected unresolved-items at {unresolvedPath}. Pipeline.Run() must emit the " +

            using (var manifestDoc = JsonDocument.Parse(File.ReadAllText(manifestPath)))

                var root = manifestDoc.RootElement;
                Assert.Equal("DatabaseManifest", root.GetProperty("SchemaType").GetString());
                Assert.Equal("1.0", root.GetProperty("SchemaVersion").GetString());
                Assert.False(string.IsNullOrEmpty(root.GetProperty("HarvesterVersion").GetString()));
                Assert.Equal(
                    "MiniComplex.accdb",
                    root.GetProperty("Database").GetProperty("Name").GetString());
            }

            using (var unresolvedDoc = JsonDocument.Parse(File.ReadAllText(unresolvedPath)))
            {
                // V1 wiring emits an empty array; downstream tooling reads
                // this file as IReadOnlyList<UnresolvedItem>. Assert array
                // shape regardless of cardinality so a future regression
                // that flips the file to an object surfaces here.
                Assert.Equal(JsonValueKind.Array, unresolvedDoc.RootElement.ValueKind);
            }
        }
        finally
        {
            if (Directory.Exists(outRoot))
                Directory.Delete(outRoot, recursive: true);
        }
    }
}
```

```csharp
using AccessHarvester.Integration.TestSupport;

using AccessHarvester.Pipeline.Validation;
using Xunit;
using CorePipeline = AccessHarvester.Core.Pipeline;

namespace AccessHarvester.Integration.Pipeline;

// Manifest-side schema-conformance gate. Closes Gap A from the prior
// integration-testing-and-acceptance set: until Session 2 wired
// Pipeline.Run() to emit a rolled-up DatabaseManifest, there was no
// document for SchemaValidator to consume against
// harvester-schema.v1.0.json. This class validates both the
// aggregator-produced shape (hermetic) and the production-pipeline-
// produced manifest.json on disk (SkippableFact integration check).
//
// Distinct from SchemaConformanceTests in this same directory: that
// class validates the committed example fixtures under examples/.
// This one validates manifests the harvester itself produces.
public sealed class ManifestSchemaConformanceTests
{
    [Fact]
    public void AggregatorMinimalManifest_ValidatesAgainstSchema()
    {
        // Exercises the contract that the smallest valid input
        // (Database + HarvesterVersion only) round-trips through
        // serialization and passes SchemaValidator. If any field
        // emitted by the envelope conflicts with the schema's
        // required/property declarations, this gate catches it.
        var database = new DatabaseInfo
        {
            Name = "Synthetic.accdb",
            FilePath = @"C:\fixtures\Synthetic.accdb",
            ExportedAt = "2026-05-18T12:00:00.0000000+00:00",
        };

        var manifest = DatabaseManifestAggregator.Build(
            database: database,
            harvesterVersion: "1.0.0-test");

        string json = JsonSerializer.Serialize(manifest, ManifestSerializerOptions);

        var result = ValidatorAgainstHarvesterSchema().Validate(json);

        Assert.True(
            result.IsValid,
            "Aggregator-produced minimal manifest failed schema validation:\n  - " +
            string.Join("\n  - ", result.Errors));
    }

    [SkippableFact]
    [SupportedOSPlatform("windows")]
    public void PipelineRunProducedManifest_ValidatesAgainstSchema()
    {
        AccessAvailability.SkipIfNoAccess();

        string db = Path.Combine(RepoPaths.Samples(), "MiniComplex.accdb");
        Skip.IfNot(File.Exists(db), $"Sample DB not present at {db}.");

        string outRoot = Path.Combine(Path.GetTempPath(), $"ah-int-manifest-{Guid.NewGuid():N}");
        try
        {

            var runResult = pipeline.Run(db, outRoot);

            string manifestPath = Path.Combine(runResult.BaseDir, "manifest.json");
            Assert.True(File.Exists(manifestPath), $"Manifest not produced at {manifestPath}.");

            string json = File.ReadAllText(manifestPath);
            var result = ValidatorAgainstHarvesterSchema().Validate(json);

            Assert.True(
                result.IsValid,
                $"Pipeline-produced manifest {manifestPath} failed schema validation:\n  - " +
                string.Join("\n  - ", result.Errors));
        }
        finally
        {
            if (Directory.Exists(outRoot))
                Directory.Delete(outRoot, recursive: true);
        }
    }

    // Shared with Pipeline.Run() — keeping the options identical
    // ensures the validator sees the same JSON the production path
    // emits.
    private static readonly JsonSerializerOptions ManifestSerializerOptions = new()
    {
        WriteIndented = true,
        DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull,
    };

    private static SchemaValidator ValidatorAgainstHarvesterSchema()
        => new(RepoPaths.SchemaFile());
}
```

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using AccessHarvester.Access;
using AccessHarvester.Pipeline.Enrichment;

namespace AccessHarvester.Pipeline.Manifest;

/// <summary>
/// Assembles per-category in-memory inputs into a single
/// <see cref="DatabaseManifest"/>. Mirrors the contract of
/// <see cref="UnresolvedItemAggregator.Build"/>: every input is
/// optional, missing inputs surface as empty arrays, and the
/// aggregator does not perform I/O.
/// </summary>
/// <remarks>
/// <para>
/// The aggregator does <b>not</b> re-sort the supplied collections.
/// Callers pass already-deterministic ordering; the aggregator
/// preserves the caller's order verbatim. The contrast with
/// <see cref="UnresolvedItemAggregator"/> is intentional — that
/// aggregator merges from multiple sources and must impose order;
/// this aggregator merges nothing — each per-category input has a
/// single producer — so order ownership stays with the caller.
/// </para>
/// <para>
/// The <see cref="DatabaseSummary"/> attached to the result is
/// computed from the populated collections, so the manifest is
/// internally consistent (i.e. <c>Forms.Count == Summary.FormCount</c>).
/// </para>
/// </remarks>
public static class DatabaseManifestAggregator
{
    /// <summary>
    /// Assemble a <see cref="DatabaseManifest"/> from the supplied
    /// inputs. <paramref name="database"/> and
    /// <paramref name="harvesterVersion"/> are required (matching
    /// the schema's <c>DatabaseManifest.required</c> contract);
    /// every other input is optional.
    /// </summary>
    /// <exception cref="ArgumentNullException">
    /// Thrown if <paramref name="database"/> is null or
    /// <paramref name="harvesterVersion"/> is null/empty.
    /// </exception>
    public static DatabaseManifest Build(
        DatabaseInfo database,
        string harvesterVersion,
        IEnumerable<FormExport>? forms = null,
        IEnumerable<FormExport>? reports = null,
        IEnumerable<QueryAbstraction>? queries = null,
        IEnumerable<ModuleExport>? modules = null,
        IEnumerable<TableMetadata>? tables = null,
        IEnumerable<RelationshipMetadata>? relationships = null,
        IEnumerable<ValidationRule>? validationRules = null,
        IEnumerable<RowSourceSpec>? rowSourceSpecs = null,
        IEnumerable<FunctionClassification>? functionClassifications = null,
        IEnumerable<EventHandlerClassification>? eventHandlerClassifications = null,
        NavigationGraph? navigationGraph = null,
        IEnumerable<UnresolvedItem>? unresolvedItems = null,
        IEnumerable<HarvesterDiagnostic>? diagnostics = null)
    {
        ArgumentNullException.ThrowIfNull(database);
        if (string.IsNullOrEmpty(harvesterVersion))
            throw new ArgumentException(
                "HarvesterVersion is required by the schema.",
                nameof(harvesterVersion));

        var formsList                       = Materialize(forms);
        var reportsList                     = Materialize(reports);
        var queriesList                     = Materialize(queries);
        var modulesList                     = Materialize(modules);
        var tablesList                      = Materialize(tables);
        var relationshipsList               = Materialize(relationships);
        var validationRulesList             = Materialize(validationRules);
        var rowSourceSpecsList              = Materialize(rowSourceSpecs);
        var functionClassificationsList     = Materialize(functionClassifications);
        var eventHandlerClassificationsList = Materialize(eventHandlerClassifications);
        var unresolvedItemsList             = Materialize(unresolvedItems);
        var diagnosticsList                 = Materialize(diagnostics);

        var summary = new DatabaseSummary
        {
            FormCount            = formsList.Count,
            ReportCount          = reportsList.Count,
            QueryCount           = queriesList.Count,
            ModuleCount          = modulesList.Count,
            TableCount           = tablesList.Count,
            UnresolvedItemCount  = unresolvedItemsList.Count,
        };

        return new DatabaseManifest
        {
            HarvesterVersion              = harvesterVersion,
            Database                      = database,
            Summary                       = summary,
            Forms                         = formsList,
            Reports                       = reportsList,
            Queries                       = queriesList,
            Modules                       = modulesList,
            Tables                        = tablesList,
            Relationships                 = relationshipsList,
            ValidationRules               = validationRulesList,
            RowSourceSpecs                = rowSourceSpecsList,
            FunctionClassifications       = functionClassificationsList,
            EventHandlerClassifications   = eventHandlerClassificationsList,
            NavigationGraph               = navigationGraph,
            UnresolvedItems               = unresolvedItemsList,
            Diagnostics                   = diagnosticsList,
        };
    }

    private static IReadOnlyList<T> Materialize<T>(IEnumerable<T>? source)
        => source is null ? Array.Empty<T>() : source.ToArray();
}
```

```csharp
/// <summary>

/// <remarks>
/// <para>

/// <c>AccessHarvester.Pipeline.Enrichment</c> rather than

    public string SchemaVersion { get; } = "1.0";
```
