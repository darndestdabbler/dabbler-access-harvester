# Runtime dependencies for the AI-led-workflow tooling in this repo.
#
# The router itself is published on PyPI as `dabbler-ai-router`; previously
# this repo carried a copy of the router source under `ai-router/` and
# every consumer script loaded it via an importlib shim. As of Set 010
# (canonical dabbler-ai-orchestration, 2026-05-02) the router is a
# regular `pip install` and `from ai_router import ...` works natively.
#
# Pin to a minimum version rather than an exact version: 0.x signals API
# may change between minor versions, so adopters bump intentionally.
#
# Floor raised to >=0.10.0 (2026-05-29): the v4 state-file writers and the
# v3->v4 / lightweight-to-v4 migrators land in 0.9.0/0.10.0. An older
# resolved version (this repo had 0.1.1) writes the legacy v2 schema, which
# the Session Set Explorer flags as "needs migration". 0.10.0 is the latest
# published release at time of writing.
dabbler-ai-router>=0.10.0
