private static readonly Dictionary<string, string> IrregularEventSuffix =
    new(StringComparer.OrdinalIgnoreCase)
{
    { "OnPush", "Click" },
};

// Modified StripOnPrefix:
private static string StripOnPrefix(string name)
{
    if (IrregularEventSuffix.TryGetValue(name, out var mapped)) return mapped;
    return name.StartsWith("On", StringComparison.Ordinal) && name.Length > 2
        ? name[2..]
        : name;
}

### Deferral rationales

**DEFERRAL 1 — QueryColumns:** The raw KB JSON `OutputColumns` field is null for every query in NorthwindDevEdition because `AccessHarvester.Core.Extraction.QueryExporter` does not yet enumerate `QueryDef.Fields`. The pre-existing typed schema (`QueryMetadata.cs`, see remarks on `QueryOutputColumn`) explicitly documents this raw-IR coverage gap. Implementing a `QueryColumnRow` writer would persist zero rows from the current input. Deferring until either (a) the raw exporter is widened, or (b) the JET SQL parser session set lands a parse-tree-driven SELECT-list extractor.

**DEFERRAL 2 — Subform nested-FQN extraction:** Subforms reference their target form via `SourceObject`, which lives in a separate KB JSON file. The current `BuildArtifacts.RunForNorthwind` deliberately loads only `frmCompanyDetail.json` (the probe target). Following subform pointers requires a multi-form extraction sweep that also keeps the probe target's surrounding context bounded. The probe target itself (`cboCompanyTypeID` on `Form_frmCompanyDetail`) is fully resolved without nested-form recursion. Schedule a multi-form follow-up before Session 5 if the migration probe needs deeper coverage.

**DEFERRAL 3 — AST clause-hash:** A structural clause hash requires a JET SQL tokenizer/parser that handles bracketed identifiers, comments, and string literals correctly. The repo has a separate `jet-sql-grammar-and-parser` session set that delivers exactly that infrastructure. Building it inside vba-symbol-db would duplicate tokenizer work. The current regex-based clause hash is documented in code as a heuristic; clause-hash/self-join equivalence canonicalisation will be re-wired once the AST is available.

**DEFERRAL 4 — BaseInfo parser:** Works correctly on every combo/list-box `BaseInfo` string in the NorthwindDevEdition fixture. A quote-aware parser is straightforward but adds an untested code path with no failing input. Re-evaluate when another sample DB ships with embedded-semicolon column names.
